# Wezterm

## Configuration

Le fichier de configuration est accessible via Powershell :

```shell
notepad $HOME\.wezterm.lua
```

Si non présent, le créer. Il sera situer dans le dossier `C:\Users\[username]\.wezterm.lua`

## Keymap

| Key                | Fonction                          |
| ------------------ | --------------------------------- |
| `Ctrl + Shift + t` | Nouvelle fenêtre dans le terminal |
| `C + S + n`        | Nouveau terminal                  |
