# Types 

## `int` 

Permet de stocker des nombre entiers.

```java 
// ======================
// déclaration d'entier
// ======================
int a = 5;

int x = 5, b = 10, c = a + b;
```

```java 
// création de variable 
String text;
// déclaration
String message = "Hello!";
// déclaration multiple
String name = "Anya", city = "New York", message = "Hello!";
